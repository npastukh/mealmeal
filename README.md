# Меню — личный конструктор

Полностью статический сайт: работает без сервера, регистрации и входа через ChatGPT. Все личные рецепты, подборки и текущий список сохраняются в браузере на устройстве.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `meal-builder`.
2. Загрузите **все файлы из этой папки** в корень репозитория. Файл `index.html` должен лежать именно в корне.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**;
   - Branch: **main**;
   - Folder: **/(root)**.
5. Нажмите **Save**. Через несколько минут появится адрес вида `https://ВАШ-ЛОГИН.github.io/meal-builder/`.

## Что есть на сайте

- точный подбор завтрака, обеда, ужина или перекуса;
- 138 встроенных вариантов с продуктами и шагами;
- простой конструктор из основы и только совместимых добавок;
- все точные совпадения по фильтрам без случайного ограничения;
- подбор по продуктам дома с понятными заменами и минимальной докупкой;
- отдельный приоритет для остатков, которые хочется использовать первыми;
- меню на 3, 5 или 7 дней с режимами «быстро», «обычные продукты» и «готовить на два дня»;
- десять подборок по ситуации и случайный выбор без недавних повторов;
- библиотека с поиском, фильтром и любимыми рецептами;
- общий список продуктов;
- собственные рецепты;
- сохранённые подборки и полный перенос личных данных через JSON;
- конструктор закусок и ужинов к разным напиткам;
- большой выбор сэндвичей, фруктовых блюд и содержательных перекусов;
- рандомайзер заказа с роллами, бургерами, пиццей, воком и другими категориями.

## Где редактировать встроенные рецепты

Все блюда находятся в `recipes.js`. Интерфейс и локальное сохранение — в `app.js`, внешний вид — в `styles.css`.

## Важно о данных

GitHub Pages не хранит пользовательские данные на сервере. Они остаются в `localStorage` конкретного браузера. Чтобы перенести свои рецепты и подборки на другое устройство, используйте кнопки «Скачать мои данные» и «Загрузить данные» в разделе «Моё».
